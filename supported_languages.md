# Supported languages

The translator supports these languages as both source and target formats:

- Bash
- C#
- C++
- Dart
- Go
- Java
- JavaScript
- Kotlin
- Lua
- PHP
- Perl
- Python
- R
- Ruby
- Rust
- Scala
- Swift
- TypeScript

Translation is limited to the shared syntax subset implemented by the translator. It does not cover every feature or library in these languages.
